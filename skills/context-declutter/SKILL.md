# context-declutter — コンテキストの読む範囲を軽くする

## 目的

AI が探索で読みにいく範囲に、読む必要のないものを置かない。
重いのは無駄なデータを見にいっているから。判断が鈍るのは必要のないデータを記憶しているから。

## 手順

1. **列挙と報告(ここで必ず止まる)**: 読む範囲にあって読む必要のないものを列挙し、理由とともに報告する。
   典型はバックアップ系、一回しか使っていない使い捨てのプログラムやバッチ、生成物。ユーザーの判断を待つ。
2. **移動**: 了承されたものは、コンテキストが読む範囲外に新しいフォルダを作ってそちらへ移す。削除はしない。
3. **除外の決定**: 残すが読ませないフォルダを決め、除外の方法を提案して了承を得てから適用する。
4. **報告**: 移動・除外した一覧と、戻し方を報告する。

## やらないこと

- 削除しない
- 何を移す・除外するかを勝手に確定しない(提案し、ユーザーが決める)
- コミット・push はしない
